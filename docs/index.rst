IMSTE documentation
===================

Iterated Minimum Spanning Tree Embedding (IMSTE) learns low-dimensional
coordinates from numeric feature vectors or a supplied sparse distance graph.
This site documents installation, the estimators, graph construction, and the
optional tools for preprocessing, tuning, and visualization.
